# Pickles Mart 🥒

A full-stack web application for ordering pickles.

## Features
- User login & registration
- Cart system (MongoDB)
- Veg & Non-veg categories
- Search functionality

## Tech Stack
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express
- Database: MongoDB

## How to Run
1. Make sure MongoDB is running locally.
2. Open a terminal in `backend` and run `npm install` once.
3. Start the application with `npm start`.
4. Open [http://localhost:5000](http://localhost:5000).

The Express server serves both the frontend and the API. If you use VS Code Live
Server instead, open `frontend/index.html`; the API still needs to be running on
port 5000.
