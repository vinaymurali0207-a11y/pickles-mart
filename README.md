# Pickles Mart 🥒

A full-stack web application for ordering pickles.

## Features
- User login & registration
- Cart system (MongoDB)
- Veg & Non-veg categories
- Search functionality

## Tech Stack
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express
- Database: MongoDB

## How to Run
1. Clone repo
2. Run `npm install`
3. Run `node server.js`
4. Open in browser
